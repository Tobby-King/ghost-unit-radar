Ghost Unit Radar

What is this, in one sentence?

Ghost Unit Radar is a spell-checker for Nigeria's list of polling units. It reads the official list, compares each polling unit with satellite data, and highlights the ones that don't add up, so someone can go and check them in person.

Why does it matter?

Nigeria has about 176,000 polling units, the places where people vote. INEC publishes a list saying where each one is. If that list is wrong, it's hard for anyone to check the election properly. And mistakes in the list are also where "ghost" polling units or padded voter numbers could hide unnoticed.

We checked the public list and found that it has real problems:

A school in Kogi State is placed in Waterloo, Canada. It is one of 1,515 polling units whose official location is outside Nigeria. Another 43,373 are piled on top of each other, 10 or more on a single spot, and 57,326 have no location at all.

What does it check?

Every polling unit is asked three simple questions:

1

Is it where it says it is?

Is the location inside Nigeria, in the right state, and not stacked on top of dozens of other units?

Uses the real public list.

2

Do enough people live there?

Satellites show roughly how many people live around each spot. If a unit has 1,700 registered voters but only about 190 adults live nearby, that's odd.

Uses real satellite population data and a made-up voter register.

3

Could the machine count that fast?

Each voter-accreditation machine (BVAS) needs about 30–120 seconds per voter. In 6 hours one machine can't accredit 1,000 people.

Uses made-up result sheets.

The traffic light

Each unit gets a score out of 100 and a colour:

Green: nothing unusual found.
Amber: worth a second look.
Red: needs someone to check it in person.

Every flag comes with a plain reason and the most likely innocent explanation (for example, "a computer guessed the location from the school's name and picked a place in Canada"). It never says "fraud". Most flags will turn out to be honest mistakes. The point is to know where to look first.

Who is it for?

INEC staff
to find and fix wrong locations in the official list before 2027.
Election observers
to decide which polling units to visit, instead of choosing at random.
Journalists and citizens
to understand the quality of public election data, with sources they can check.

How is it built? (the architecture)

It's four simple pieces in a line. Data goes in on the left, a website comes out on the right:

1 · Inputs

Public data files

  • INEC polling-unit list (176,623 units, public)
  • State boundary map
  • Satellite population map (WorldPop)
  • Made-up voter registers and result sheets
2 · The engine

Python pipeline

  • Runs the 3 checks on every unit
  • Adds up a score and writes the reasons
  • Runs on a laptop in about 25 seconds
  • 44 automatic tests
3 · Results

Plain files

  • One small data file per state (JSON)
  • Spreadsheet of units to check (CSV)
  • National summary
4 · Website

Map in your browser

  • Static site hosted on Vercel
  • Map, filters, unit cards, download
  • Works on phones
  • 85 automatic browser tests
Optional add-on: a Google Earth Engine script counts rooftops around each unit from satellite images (2016–2023), so the tool can say "1,400 voters but only 38 buildings". It plugs into step 2.

What it deliberately does not have

  • No connection to INEC's live systems (IReV, voter portal)
  • No personal data: no voter names or numbers
  • No database or server to hack, only read-only files
  • No login, tracking or accounts
  • No party, candidate or vote-count data (non-partisan)
  • No hidden AI "black box": every score is a sum of written rules

Because the website is just files, it's cheap to run, fast, and hard to tamper with. Re-running the engine with new data (for example, INEC's real register under INEC's authority) updates everything.
